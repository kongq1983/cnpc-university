DATABASE METADATA WORKSPACE

配置 db-docs

连接运行中的数据库，只读取表结构元数据。

LOCAL ONLY
01

数据库连接

填写连接信息后测试，成功后才能选择 namespace。

METADATA ONLY
支持绝对路径或相对于当前工作目录的路径。
02

选择 Catalog / Schema

连接成功后从可读取的 namespace 中选择文档范围。

REQUIRED
先点击“测试连接”，这里会显示可选择的 namespace。
准备好生成数据字典了吗？配置会保存到本机用户目录，生成阶段只读取元数据。

这一步会做什么？

建立一个只读的元数据连接，生成表、字段、约束和索引说明。不会查询业务行。

  1. 01填写连接信息
  2. 02测试连接并选择 namespace
  3. 03保存后运行文档生成

当前支持

配置页支持 MySQL、PostgreSQL、Oracle 和 SQLite。SQL Server 暂不支持。

保存位置~/.config/db-docs
运行方式LOCAL HTTP
